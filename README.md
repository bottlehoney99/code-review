# 파이썬 실험실

파이썬 실습 코드를 붙여 넣으면 교사가 등록한 테스트 케이스로 바로 채점해 주는 웹 페이지입니다.
파이썬은 브라우저 안에서 [Skulpt](https://skulpt.org)로 실행되므로 서버가 필요 없습니다.

## 학생

사이트 주소로 들어가 문제를 고르고, 코드를 작성한 뒤 **채점하기**를 누릅니다.
케이스마다 통과·틀림·오류·시간 초과(2초)가 표시되고, 공개 예제는 기대 출력과 내 출력을 나란히 보여 줍니다.

문제는 207개이고, 조건문 연습, 별 찍기, for 반복문(15), while 반복문(15) 묶음이 따로 있습니다. 반복문 문제는 설명 끝의 '유형:' 줄에 반복 유형(범위 출력, 누적, 중첩 반복, break·continue, 끝 표시가 나올 때까지, 목표값에 닿을 때까지 등)을 적어 두었습니다. '파이썬 기초'는 81문제로, 2026년 10월에 난이도별 50문제(id가 `bx_`로 시작)를 더했습니다. 그중 7문제는 IT소프트웨어과 학교생활을 배경으로 한 이야기 문제입니다. 모두 난이도가 다섯 단계(매우 쉬움, 쉬움, 보통, 어려움, 매우 어려움)로 표시됩니다.
목록 위의 난이도 버튼으로 원하는 단계만 골라 볼 수 있습니다. 문제 목록은 주제별로 접고 펼 수 있고(처음에는 지금 문제의 주제만 열림), 목록만 따로 스크롤됩니다. 매우 쉬움은 처음 배우는 학생용이고, 어려움 이상은 빨리 끝낸 학생이 남는 시간에 도전하는 문제입니다.

## 교사: 문제 고치기

1. 수업 현황(`teacher.html`) 머리글의 **문제 수정**을 누르거나, 사이트 주소 끝에 `#edit`를 붙여 엽니다.
2. 교사 비밀번호를 넣으면 문제 관리 화면이 열립니다. 문제를 고치거나 추가·삭제합니다. 모범 답안을 넣고 실행하면 기대값이 자동으로 채워집니다.
3. **저장해서 학생 화면에 반영**을 누릅니다. 문제는 Supabase에 저장되고, 학생이 페이지를 새로고침하면 바뀐 문제가 보입니다.

- 서버에 저장한 문제가 있으면 사이트는 그것을 쓰고, 없을 때만 저장소의 `problems.json`을 씁니다. 처음 저장할 때 지금의 문제 전체가 서버로 옮겨집니다. `index.html` 안에는 문제를 넣지 않습니다(아티팩트로 저장할 때만 들어감).
- 저장하는 동안 다른 칸을 고치면 그 내용은 이번 저장에 들어가지 않고, "한 번 더 저장하세요"라고 나옵니다.
- 저장할 때마다 이전 저장본이 최근 30개까지 `private.problem_set_history`에 남습니다.
- 두 창에서 동시에 고치면 나중에 저장한 쪽은 거절됩니다. **JSON 백업 복사**로 내용을 챙긴 뒤 새로고침하세요.

## 학습 기록

학생은 처음 들어올 때 교사가 나눠 준 다섯 글자 학생 코드를 넣습니다. 이름이나 학번은 받지 않습니다.
채점할 때마다 문제, 통과한 케이스 수, 케이스별 결과, 제출한 코드가 Supabase에 저장됩니다.
코드는 브라우저에 기억되므로 같은 기기에서는 다시 넣지 않아도 되고, 다른 기기에서 같은 코드를 넣으면 '맞음' 표시가 그대로 돌아옵니다.
컴퓨터실처럼 여러 학생이 쓰는 기기를 위해, 마지막으로 쓴 지 1시간이 지나서 열면 "학생 코드 ○○○○○ 맞나요?"를 먼저 묻습니다. 편집기 초안은 학생 코드별로 따로 저장됩니다.
인터넷이 끊겨 못 보낸 기록은 브라우저에 모아 두었다가 연결되면 다시 보냅니다. 제출마다 고유 번호가 있어서 두 번 보내져도 한 번만 저장됩니다.

교사는 `teacher.html`에서 교사 비밀번호로 들어가 5초마다 갱신되는 현황을 봅니다.
학생별 진행, 문제별로 다 맞힌 학생 수, 최근 제출, 학생 한 명의 문제별 마지막 제출 코드와 케이스 결과를 볼 수 있습니다.
이름 메모는 그 컴퓨터 브라우저에만 저장되고 서버로 가지 않습니다.

학생은 머리글의 **내 기록**에서 다 맞힌 문제 수, 난이도별 진행, 도장(첫 정답, 10·30·60·100문제, 어려움 이상 첫 정답, 한 번에 맞힌 문제 5개), 아직 못 맞힌 문제 목록을 봅니다. 다 맞힌 문제를 누르면 그때 맞힌 코드를 다시 볼 수 있고, 편집기에 불러올 수도 있습니다.
현황판의 학생 상세에서는 문제마다 '마지막 코드'와 '정답 코드'(가장 최근에 다 맞힌 코드)를 따로 볼 수 있습니다.
학생 화면 맨 위에는 **이달의 MVP** 띠가 고정되어 있습니다. 한국 시간 기준 이번 달에 처음 다 맞힌 문제가 가장 많은 학생의 별명이 나오고, 같으면 그 개수에 먼저 도달한 학생입니다. 이번 달에 아직 아무도 못 맞혔으면 지난달 MVP가 나옵니다.
`ranking.html`은 다 맞힌 문제 수 상위 3명을 보여 주는 화면으로, 교실 화면에 띄워 두면 10초마다 갱신됩니다.
순위에는 학생 코드 대신 코드마다 정해진 별명(예: 날쌘 고래)이 나옵니다. 학생은 '내 기록'에서 별명을 직접 바꿀 수 있습니다(2~10자, 한글·영어·숫자, 겹치는 별명과 욕설은 거절, 10분에 한 번). 현황판에서 학생을 열고 '원래 별명으로'를 누르면 처음 받은 별명으로 돌아갑니다. 코드를 추가할 때 별명도 함께 넣으려면 `insert into private.students(code, alias) values ('ABCDE', '씩씩한 해마');`처럼 실행합니다.

- 표는 API에 드러나지 않는 `private` 스키마에 있고, 페이지는 `check_code`, `submit_run`, `my_progress`, `teacher_*` 함수로만 접근합니다.
- 서버 표와 함수는 `supabase/migrations/`에 SQL로 남겨 두었습니다. 첫 파일은 2026-10-28 기준 상태를 옮겨 적은 것이고, 두 번째 파일이 제출 검증과 교사 로그인 제한을 더합니다. 두 번째 파일은 SQL Editor에서 한 번 실행해야 적용됩니다. 실행 전에도 사이트는 예전 함수로 동작합니다.
- 제출할 때 서버는 문제의 케이스 수와 맞는지 보고, 통과 수를 케이스 결과에서 직접 셉니다. 교사가 문제를 고친 뒤 새로고침하지 않은 화면의 결과는 기록되지 않고, 학생에게 새로고침하라고 안내합니다.
- 교사 비밀번호는 로그인할 때만 확인하고, 이후에는 12시간짜리 로그인 토큰을 씁니다. 같은 곳에서 10분에 10번 넘게 틀리면 10분 동안 로그인이 막힙니다.
- 학생 코드를 추가하려면 Supabase SQL Editor에서 `insert into private.students(code) values ('ABCDE');`를 실행합니다.
- 무료 플랜은 1주일 동안 요청이 없으면 프로젝트가 일시정지됩니다. 방학 뒤 첫 수업 전에 대시보드에서 켜져 있는지 확인하세요.

## 알아 둘 점

- 숨김 케이스는 학생 화면에는 나오지 않지만, 채점이 브라우저에서 이루어지므로 개발자 도구로 찾아볼 수는 있습니다. 같은 이유로 개발자 도구를 쓸 줄 아는 학생은 결과를 꾸며 보낼 수 있습니다. 서버 검사로 숫자만 바꾼 위조는 막지만, 완전히 막으려면 서버에서 다시 채점해야 합니다. 제출 코드가 함께 저장되니 순위가 이상하면 현황판에서 코드를 확인하세요.
- 함수 문제의 반환값은 학생 코드 밖에서 비교합니다. int, float, str, bool, None, list, tuple, dict, set만 정답이 될 수 있고, 학생이 만든 클래스나 이를 상속한 값은 오답입니다.
- 채점, 직접 실행, 모범 답안 실행은 한 번에 하나씩 차례로 돕니다. 케이스마다 2초가 지나면 시간 초과가 됩니다. 무한 반복을 채점하는 동안에는 화면이 잠시 멈춥니다. Skulpt 1.2.0은 실행 중간에 브라우저로 차례를 넘기면(`yieldLimit`) 함수 결과를 잃어버리는 버그가 있어 이 기능을 쓰지 않습니다.
- Skulpt는 실제 파이썬과 조금 다른 부분이 있습니다. 예를 들어 `round(2.675, 2)`가 2.68로 나오고, numpy 같은 외부 라이브러리는 쓸 수 없습니다.
- AI 힌트 기능은 claude.ai에서 연 페이지에서만 동작하고, GitHub Pages 사이트에서는 나타나지 않습니다.
