# 파이썬 실험실

파이썬 실습 코드를 붙여 넣으면 교사가 등록한 테스트 케이스로 바로 채점해 주는 웹 페이지입니다.
파이썬은 브라우저 안에서 [Skulpt](https://skulpt.org)로 실행되므로 서버가 필요 없습니다.

## 학생

사이트 주소로 들어가 문제를 고르고, 코드를 작성한 뒤 **채점하기**를 누릅니다.
케이스마다 통과·틀림·오류·시간 초과(2초)가 표시되고, 공개 예제는 기대 출력과 내 출력을 나란히 보여 줍니다.

문제는 127개이고, 조건문 연습과 별 찍기 묶음이 따로 있습니다. 모두 난이도가 다섯 단계(매우 쉬움, 쉬움, 보통, 어려움, 매우 어려움)로 표시됩니다.
목록 위의 난이도 버튼으로 원하는 단계만 골라 볼 수 있습니다. 매우 쉬움은 처음 배우는 학생용이고, 어려움 이상은 빨리 끝낸 학생이 남는 시간에 도전하는 문제입니다.

## 교사: 문제 고치기

1. 사이트 주소 끝에 `#edit`를 붙여 엽니다. 예: `https://<아이디>.github.io/code_review/#edit`
2. 문제 관리 화면에서 문제를 고치거나 추가합니다. 모범 답안을 넣고 실행하면 기대값이 자동으로 채워집니다.
3. **problems.json 내용 복사**를 누릅니다.
4. 이 저장소의 `problems.json`을 열고 연필 아이콘(Edit)을 눌러 내용을 모두 지운 뒤 붙여 넣고 **Commit changes**를 누릅니다.
5. 1~2분 뒤 사이트에 반영됩니다.

`#edit` 화면은 누구나 열 수 있지만, 실제 반영은 저장소에 커밋할 수 있는 사람만 할 수 있습니다.

## 학습 기록

학생은 처음 들어올 때 교사가 나눠 준 다섯 글자 학생 코드를 넣습니다. 이름이나 학번은 받지 않습니다.
채점할 때마다 문제, 통과한 케이스 수, 케이스별 결과, 제출한 코드가 Supabase에 저장됩니다.
코드는 브라우저에 기억되므로 같은 기기에서는 다시 넣지 않아도 되고, 다른 기기에서 같은 코드를 넣으면 '맞음' 표시가 그대로 돌아옵니다.

교사는 `teacher.html`에서 교사 비밀번호로 들어가 5초마다 갱신되는 현황을 봅니다.
학생별 진행, 문제별로 다 맞힌 학생 수, 최근 제출, 학생 한 명의 문제별 마지막 제출 코드와 케이스 결과를 볼 수 있습니다.
이름 메모는 그 컴퓨터 브라우저에만 저장되고 서버로 가지 않습니다.

- 표는 API에 드러나지 않는 `private` 스키마에 있고, 페이지는 `check_code`, `submit_result`, `my_progress`, `teacher_*` 함수로만 접근합니다.
- 학생 코드를 추가하려면 Supabase SQL Editor에서 `insert into private.students(code) values ('ABCDE');`를 실행합니다.
- 무료 플랜은 1주일 동안 요청이 없으면 프로젝트가 일시정지됩니다. 방학 뒤 첫 수업 전에 대시보드에서 켜져 있는지 확인하세요.

## 알아 둘 점

- 숨김 케이스는 학생 화면에는 나오지 않지만 공개 저장소의 `problems.json`에서 볼 수 있습니다.
- Skulpt는 실제 파이썬과 조금 다른 부분이 있습니다. 예를 들어 `round(2.675, 2)`가 2.68로 나오고, numpy 같은 외부 라이브러리는 쓸 수 없습니다.
- AI 힌트 기능은 claude.ai에서 연 페이지에서만 동작하고, GitHub Pages 사이트에서는 나타나지 않습니다.
